# 🛡️ 個資保衛戰｜個資資安事件風險與應對 課間測驗

以「故事闖關」方式複習《個資資安事件風險與應對》課程的互動測驗網站。
純前端（HTML / CSS / JavaScript），不需後端、不需登入、不蒐集任何個資，可直接部署於 GitHub Pages。

## 內容

跟著新進員工「小安」走過 8 個真實改編的個資外洩與詐騙現場，共 60 題（單選＋是非），每題附完整解析：

| 關卡 | 主題 | 對應課程章節 |
| --- | --- | --- |
| 1 📱 釣魚簡訊的陷阱 | 釣魚簡訊攻擊流程、集團分工、三流追查、加重詐欺 | 金融帳戶資訊外洩 |
| 2 🔑 密碼撞庫大作戰 | 2021 證券商撞庫事件、三大防禦、F-ISAC | 證券個資資訊外洩 |
| 3 🎭 包著糖衣的毒藥 | 社交工程、Bybit 事件、假檢警／假投資／求職陷阱／BEC | 社交工程 |
| 4 💬 請投我兒子一票 | LINE 帳號盜用四步驟、驗證碼防護 | 某地院公務群組遭駭 |
| 5 🛡️ 從 OTP 到 FIDO | SIM Swap、Passkey 原理、零信任三層檢驗、信用卡盜刷 | OTP 到 FIDO－零信任 |
| 6 🤖 AI 與個資外洩 | 知情同意與被遺忘權、Privacy by Design、Machine Unlearning | AI 與個資外洩 |
| 7 ⚖️ 個資法大考驗 | 個資定義、第 27 條安全措施、罰鍰、外洩通知、72 小時通報 | 個人資料保護法與個資外洩之預防 |
| 8 🤝 補破網 | 個資法第 16 條但書、詐防條例義務、金融機構定義 | 異常通報與檢警合作 |

## 兩種模式

- **📖 故事闖關**：8 個章節自由選關，先看故事再作答，紀錄最佳成績與星等（存於瀏覽器 localStorage）。
- **⚡ 快問快答**：從 60 題隨機抽 10 題，每題 20 秒倒數，適合課間搶答。

## 課堂使用建議

- 點右上角「🖥️ 投影模式」放大字體。
- 鍵盤 `1`–`4`（或 `A`–`D`）作答、`O`/`X` 回答是非題、`Enter` 下一題，講師可以一手操作。
- 全部章節完成後，關卡地圖會出現「查看結業稱號」，可複製成績文字分享。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可；或在資料夾下執行：

```bash
python -m http.server 8080
```

## 部署到 GitHub Pages

1. 將整個資料夾推送到 GitHub 儲存庫的 `main` 分支。
2. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main` / `/ (root)`，儲存。
3. 數分鐘後即可在 `https://<帳號>.github.io/<儲存庫名稱>/` 使用。

## 修改題目

所有題目都在 [`js/questions.js`](js/questions.js)，每一關是一個物件：

```js
{
  id: 1, icon: "📱", scene: "phone", title: "…", subtitle: "…", color: "#ff7a59",
  story: ["段落一", "段落二"],
  questions: [
    { type: "choice", q: "題目", options: ["A", "B", "C", "D"], answer: 1, explain: "解析" },
    { type: "tf", q: "是非題敘述", answer: false, explain: "解析" }
  ]
}
```

`answer` 為正確選項的索引（從 0 起算）；選項在作答時會自動打亂順序。
`scene` 對應 [`js/scenes.js`](js/scenes.js) 內的插畫函式。
